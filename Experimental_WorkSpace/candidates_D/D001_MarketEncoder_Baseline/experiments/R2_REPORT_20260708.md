## Interpretation

R2 improves validation quality materially over R1 and the official baseline under the new three-set validation protocol. The light portfolio objective (`portfolio_return_weight=0.05`, `portfolio_volatility_weight=0.01`) is the only tested change that improved robust validation score.

The model is still not stable enough for promotion. Validation improves while holdout-backtest and the one-week test remain negative, which indicates either regime shift in late February/March 2026 or residual overfitting to the validation period.

## Next Changes

- Add a regime-aware checkpoint gate: require validation robust improvement and non-catastrophic local-test diagnostics before treating a run as champion.
- Search portfolio size and cash behavior after training rather than retraining, because top_k changes the scoring surface but not the current model loss.
- Try a stronger downside-aware objective that directly penalizes worst validation-style days instead of only mean portfolio return.
- Add seed ensembling or checkpoint averaging only after validating it on the three-set protocol; a single alternate seed did not improve validation robust score.

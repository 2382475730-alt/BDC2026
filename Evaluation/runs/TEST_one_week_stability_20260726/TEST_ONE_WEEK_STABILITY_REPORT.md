## 决赛导向的修正顺序

1. 暂停把 F/G 外部数据并入正式模型；先保持 Candidate-D 为正式基线。
2. 把训练目标改为与提交一致的 hard top-k surrogate，并在 top-3/top-5 上做固定权重验证；不得用最终一周或封存区间选择 k。
3. checkpoint 选择与周度报告分离：内层选 checkpoint，外层只评一次；每个分支至少 3 个固定种子，以排名共识而非单模型分数选股。
4. 财报改成真实版本化的公告时点数据，只保留公告事件、同比/环比 surprise、距公告 1/3/5/10 日衰减和逐字段缺失标记；删除陈旧绝对水平。
5. 行业改为历史点时分类；期货改为相对现货的 basis、期限结构和隔夜/日内风险状态，所有收盘特征至少明确 T 日收盘后的可用时刻。
6. 最终输出只允许使用开发期预注册策略：优先 HHI<=0.30、top-5 等权或固定30/25/20/15/10；只有在嵌套验证下同时改善中位数、CVaR20 和去最佳两周结果时，才允许替换 top-2。

本审计使用 2025Q1/Q2/Q3 与 2026Q1 共 53 个非重叠周。它不访问封存区间，不修改 `candidate/`，也不构成 F01/G01 晋级证据。

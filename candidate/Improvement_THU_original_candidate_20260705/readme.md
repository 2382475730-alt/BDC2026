# Code Description

## Environment

The submission runs in the official container with `/app` as the working directory. The main runtime is Python with PyTorch, pandas, scikit-learn, TA-Lib, joblib, tqdm, and tensorboardX.

`init.sh`, `train.sh`, and `test.sh` use only local files in this package. They do not call network download code. The Docker image name remains `bdc2026`.

## Data

Training data is `data/train.csv`. Local self-evaluation data is `data/test.csv`.

Both files follow the official CSV schema used by the reference code, including stock code, date, open, close, high, low, volume, amount, amplitude, change amount, turnover, and change percentage columns. Stock codes are read as strings and padded to six digits.

## Pretrained Models

No public pretrained model, embedding, or closed-source artifact is used.

The files under `model/60_158+39/` are artifacts generated from the packaged training data: Transformer checkpoints, scaler, training config, final score log, and rerank config. They can be regenerated by running `bash train.sh`.

## Algorithm

The core model remains the official-copy Transformer stock ranking pipeline.

The training target is the open-to-open forward return from the next trading day to the fifth following trading day. For each trading date, stocks are organized as one cross-sectional ranking sample. Labels are winsorized and normalized within the cross-section.

The model uses:

1. Rolling technical and alpha-style features (`158+39` feature set).
2. Sequence length 60.
3. `StockTransformer` with temporal encoding, feature attention, and cross-stock attention.
4. A ranking loss combining listwise relevance, top/bottom boundary separation, global cross entropy, and score regularization.
5. Multi-window validation for robust checkpoint selection.

Inference uses the best checkpoint plus the second-best checkpoint when available. The latest cross-section is normalized, scored by the Transformer, then reranked with a small set of technical risk and short-horizon structure factors.

Current fixed rerank settings:

```text
pool_size = 150
rerank_return_5_weight = -3.0
rerank_volume_change_weight = 0.8
rerank_volatility_10_weight = -0.3
rerank_extra_weights = {
  atr_14: 1.0,
  open_close_spread: 1.5,
  volume_ratio: -1.0
}
output_top_k = 5
weight_mode = floor_capped_softmax
softmax_temperature = 0.03
min_weight = 0.05
max_weight = 0.5
```

This keeps the output diversified enough for the local risk-control rule: exactly five stocks, each stock at least 5% and at most 50%, with total weight equal to 1.

## Training Flow

Run:

```bash
bash init.sh
bash train.sh
```

`train.sh` executes `code/src/train.py`. The training script:

1. Reads `data/train.csv`.
2. Builds stock ID mappings and rolling features.
3. Splits the last period into validation windows.
4. Fits and saves the feature scaler.
5. Trains the Transformer ranking model.
6. Saves `best_model.pth`, optional `second_best_model.pth`, `config.json`, `final_score.txt`, and `rerank_config.json`.

The training-side rerank validation supports the same output controls used by inference, including `floor_capped_softmax` and configurable extra rerank factors.

## Inference Flow

Run:

```bash
bash test.sh
```

`test.sh` calls `code/src/test.py`, which calls `code/src/predict.py` and writes `output/result.csv`.

The output file header is exactly:

```text
stock_id,weight
```

The current packaged output contains five unique stock codes. Weights are non-negative, sum to 1, and each stock weight is between 0.05 and 0.5.

## Other Notes

- `code/src/featurework.py` performs local CSV structure checks.
- `code/src/score_self.py` computes the local five-day open-to-open self-score and writes `temp/tmp.csv`.
- `code/src/validate_submission.py` checks package structure, README sections, `output/result.csv`, source manifest, and size budget.
- `code/submission_manifest.json` is generated from source and script files for packaging review.
